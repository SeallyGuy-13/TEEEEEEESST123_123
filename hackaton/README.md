# ЭкоМониторинг: Стажёр

Образовательная визуальная новелла о технологиях экологического мониторинга.
Новелла собрана на **Monogatari**, мини-игры — на **чистом JavaScript**,
готовая игра «три в ряд» подключается через адаптер.

Игрок — новый стажёр. Он выбирает задачу в трекере, проходит инструктаж,
отвечает на проверочный вопрос и только после этого выполняет практическое
задание в мини-игре. Смысл всей игры — показать цепочку
**данные → проверка → анализ → решение → действие**, а не «нашёл пятно —
зови волонтёров».

## Запуск

Игру нужно открывать через локальный сервер: страницы читают `data/*.json`
через `fetch`, а с `file://` браузер это блокирует.

```bash
npm start
```

Затем откройте:

| Адрес | Что это |
| --- | --- |
| `http://localhost:5173/` | полная новелла |
| `http://localhost:5173/stand/match3.html` | стендовый режим «три в ряд» |
| `http://localhost:5173/stand/match3.html?level=stand_cleanup_01` | стенд с конкретным уровнем |
| `http://localhost:5173/minigames/match3/standalone.html` | «три в ряд» отдельно |
| `http://localhost:5173/minigames/drone/standalone.html` | игра про дрон отдельно (все 5 участков) |

Node нужен только для сервера и генератора ассетов — сборки у проекта нет,
это статические файлы.

## Что уже работает

- Пролог с выборами и характером героя.
- Трекер задач как главный хаб: игрок сам выбирает порядок.
- Четыре учебных направления: БПЛА, снимки, анализ данных, очистка территории.
- Обследование с БПЛА — подключённая игра «Эко-Дрон: Чистый Берег»: игрок чертит
  маршрут, экономит заряд и облетает участки; сколько участков нужно пройти,
  задаётся в `data/minigames.json`.
- Очистка территории — подключённая игра «Эко-Радар: Чистый Берег»: она получает
  уровень из новеллы и возвращает в неё результат (`docs/INTEGRATION.md`).
- Инструктаж → проверка знаний → мини-игра → результат → возврат в трекер.
- Инструктаж не повторяется автоматически, но открывается кнопкой
  «Повторить инструктаж».
- Репутация стажёра (0–100), XP, уровни доступа, компетенции, коллекция фактов.
- При падении репутации до нуля — не Game Over, а возврат к чекпоинту.
- Финал базового обучения: в трекере открывается карточка реальной активности.
- Сохранение в localStorage, восстановление после перезагрузки.
- Стендовый режим «три в ряд» без прохождения новеллы.
- Адаптив: телефон (портрет и ландшафт), планшет, ПК; управление мышью,
  клавиатурой и касанием.

## Что нужно заменить

Всё перечисленное — заглушки. Заменяются файл в файл, без правок кода.

| Что | Где | Как |
| --- | --- | --- |
| Спрайты персонажей | `assets/characters/<роль>/normal.svg` | тот же путь и имя (можно `.png`, тогда поправьте `sprites` в `js/script.js`) |
| Фоны сцен | `assets/scenes/*.svg` | те же имена |
| Снимки для мини-игр | `assets/scenes/img_*.svg` | те же имена; координаты хотспотов — в `data/minigames.json` |
| Музыка | `assets/audio/music/*.wav` | те же имена (или поменяйте расширения в `monogatari.assets('music', …)`) |
| Звуки | `assets/audio/sound/*.wav` | то же самое |

Пересобрать болванки заново: `npm run assets`.

## Как добавить новое направление

Без правок пролога и навигации (ТЗ, п. 20):

1. Карточка задачи в `data/tasks.json`.
2. Проверка знаний в `data/quizzes.json`.
3. Конфиг мини-игры в `data/minigames.json`.
4. Ветка сценария в `js/script.js` + ветка в `Conditional` метки `Tracker`.
5. Адаптер в `js/minigames/`, если тип мини-игры новый.
6. Ассеты.

## Отладка

В консоли браузера доступен объект `game`:

```js
game.monogatari.storage()          // всё состояние
game.Progress.reputation(-10)      // изменить репутацию
game.monogatari.run('jump Tracker')// прыгнуть на метку
game.MinigameHost.start('drone', 'drone_level_01')  // запустить мини-игру
```
